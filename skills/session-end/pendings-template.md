# Pendências

Registro vivo do que ficou em aberto e por quê. Cada item diz o que é, por que não
foi feito agora, e o que custa fazer. Remova o item quando resolver.

- Trate cada item deste arquivo como uma demanda individual, e após concluída, você deve remover a demanda do arquivo.
- Você não deve apagar este cabeçalho, este arquivo sempre vai existir, mesmo que livre de demandas.
